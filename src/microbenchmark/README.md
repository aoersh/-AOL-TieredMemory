# 微基准

该程序生成两类访问：指针追踪和顺序读取。默认使用随机指针追踪；顺序读取通常产生更高的内存访问强度。它用于检查访问模式、NUMA 放置和 SOAR/ALTO 基础行为，不代表 DNN 训练性能。

## 使用

```bash
make
./bench -R 0.0 -i 9 -A 1024   # 指针追踪，A 为 MiB
./bench -R 1.0 -i 9 -B 1024   # 顺序读取，B 为 MiB
./bench -R 0.5 -i 9 -A 1024 -B 1024
```

`-i` 是迭代次数，`-R` 控制随机程度；具体参数以 `./bench --help` 和源码为准。
